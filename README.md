# Task 6: K-Nearest Neighbors (KNN) Classification

## 📌 Objective

The objective of this project is to understand and implement the K-Nearest Neighbors (KNN) algorithm for classification problems using the Iris dataset. The project includes feature normalization, model training, K-value comparison, confusion matrix analysis, and decision boundary visualization.

## 📂 Dataset

* Iris Dataset (`Iris.csv`)

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## 📋 Project Workflow

1. Imported the Iris dataset.
2. Performed data exploration.
3. Split the dataset into training and testing sets.
4. Normalized features using `StandardScaler`.
5. Trained a K-Nearest Neighbors classifier.
6. Evaluated the model using accuracy score.
7. Generated a confusion matrix and classification report.
8. Tested different values of **K**.
9. Plotted **Accuracy vs K**.
10. Visualized the KNN decision boundary.

## 📊 Results

* Successfully implemented KNN classification.
* Compared model performance for different K values.
* Generated confusion matrix and classification report.
* Visualized the decision boundary using two input features.
* Identified the best K value based on test accuracy.
